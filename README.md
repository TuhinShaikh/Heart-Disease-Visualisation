Heart Disease Analysis

A data analysis project in Python that explores the Heart Failure Prediction dataset. It cleans the data, answers six questions with Pandas, and backs each answer with a chart, a conclusion and a recommendation.

All the work is in one notebook: Heart_Disease_Analysis.ipynb.

Dataset
Name: Heart Failure Prediction Dataset (heart.csv)
Source: Kaggle
Size: 918 patients and 12 columns (917 patients after cleaning)
